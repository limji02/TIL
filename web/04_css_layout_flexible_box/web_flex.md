## CSS flexbox

요소를 행과 열 형태로 배치하는 1차원 레이아웃 방식\
공간 배열, 정렬

### flexbox 구성요소

1. main axis
2. cross axis
3. flex container
4. flex item


### flexbox 속성

1. flex container 관련 속성
  - display
  - flex-firection
  - flex-wrap
  - justify-content
  - align-items
  - align-content
  
2. flex item 관련 속성
  - align-self
  - flex-grow
  - flex-basis
  - order
