# [PJT 03] 금융 상품 비교 애플리케이션

## 임지영

## 1. 프로젝트 개요
* **목표**: HTML, CSS, Bootstrap5를 활용한 금융 상품 비교 애플리케이션 프로필 페이지 구현 (반응형 web)
* **진행 일자**: 2026.03.06
* **주요 기술**: HTML5, CSS3, Bootstrap5, Media Query

---

## 2. 요구사항 분석 및 구현 현황

### 필수 기능 (기본)
- [ ] **F301: 프로필 및 투자 성향 출력** 
    - 프로필 사진 (타원/원형, 그림자 적용) 
    - 자기소개 (Textarea, Button 활용)
    - 투자 성향 (선택지/목록 구성 및 좌우 배치)
- [ ] **F302: 회원 정보 출력**
    - 회원 번호, ID (편집 불가 필드)
    - Email, 나이, 자산/연봉 (적절한 Input 속성 적용)
- [ ] **F303: 네비게이션 바** 
    - 기본 정보 수정 및 포트폴리오 수정 페이지 간 이동 링크 구현 
- [ ] **F304: 금융 포트폴리오 정보 출력**
    - 저축 성향(라디오), 최애 은행(텍스트) 등 출력 및 수정 UI
- [ ] **F305: 반응형 레이아웃 구성** 
    - 768px 미만 시 투자 성향 파트가 자기소개 밑으로 배치되도록 구현

### 심화 기능 (선택)
- [ ] **F310: 생성형 AI 활용**
    - OpenAI, Gemini 등을 활용한 UI/UX 디자인 개선 아이디어 반영

## 3. 핵심 학습 내용
* **Bootstrap Grid 시스템**: `row`, `col` 클래스를 활용하여 복잡한 레이아웃을 효율적으로 배치하는 법을 익힘.
* **반응형 웹 디자인**: Media Query를 통해 해상도(768px)에 따라 요소의 배치가 동적으로 변하는 원리를 이해함[cite: 154].
* **Semantic Tag 및 Input 속성**: 데이터의 성격(이메일, 숫자, 읽기 전용)에 맞는 올바른 HTML 태그 사용의 중요성을 학습함[cite: 89].

## 4. 어려웠던 점 및 해결 방법

* **문제점**: (예: 화면 사이즈가 줄어들 때 프로필 이미지가 깨지는 현상 등)
* **해결 방법**: (예: `img-fluid` 클래스 적용 및 미디어 쿼리 세부 조정 등)
* * **새로 배운 것**: 프로젝트를 통해 새롭게 알게 된 점 기록
* **느낀 점**: 페어와 역할 분담을 통해 협업하며 느낀 점 기록
