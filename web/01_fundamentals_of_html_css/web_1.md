## HTML
: HyperText MarkupText

HyperText : 웹페이지를 다른 페이지로 연결하는 링크
- 참조를 통해 문서 접근
- 비선형성 / 상호연결성 / 사용자 주도적 탐색
Markup Language : 태그 등을 이용해 문서나 데이터의 구조를 명시하는 언어
- 데이터의 구조와 의미를 정의
- HTML, Markdown

### HTML 구조
```
<!DOCTYPE html>  # 해당 문서가 html 문서라는 것을 나타냄
<html lang="en">  # 전체 페이지의 콘텐츠를 포함

<head>
  <meta charset="UTF-8">  # 닫는 태그가 없는 경우, 속성을 나타내거나... 등등.
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>  # 브라우저 탭 및 즐겨찾기 시 표시되는 제목
</head>

<body>  # 하나의 문서에는 하나의 body만 존재
</body>

</html>

```

### HTML 속성
- 나타내고 싶지 않은 것들
- 그러나 부가 기능, 내용 담고 싶을 때
- CSS에서 스타일 적용을 위해 해당 요소를 선택하기 위한 값으로 활용
  
- 작성 규칙
  1. 속성은 요소 이름과 속서 사이에 공백이 있어야 함
  2. 하나 이상의 속성들이 있는 경우엔 속성 사이에 공백으로 구분함
  3. 속성 값은 열고 닫는 따옴표로 감사야 함
   
- ! enter하면 기본 코드 바로 나타남

## CSS
Cascading Style Sheet
웹 페이지의 디자인과 레이아웃을 구성하는 언어

### CSS 적용 방법
1. inline 스타일 (가장 비권장)
   - 요소 안에 style 속성 값
2. internal 스타일 시트
   - head 태그 안에 style 태그
3. external 스타일 시트 (가장 권장)
   - 별도 css 파일 생성 후 link 태그 사용해 불러오기

## CSS 구문
### 선택자 Selectors
"어떤 요소에" 스타일을 적용할지 결정하는 규칙

- 선택자 
  - 전체 (*)
  - 요소 (tag)
  - 클래스 (.) : 재사용성 높음
  - 아이디 (#) : 그래서 문서에는 주어진 아이디를 가진 요소가 하나만 있어야 함
  - 속성 ([])
  - 자손 결합자 (" " (space)) : 첫 번째 요소의 자손 요소들 선택
  - 자식 결합자 (">") : 첫 번째 요소의 직계 자식만 선택
- 명시도
  - 결과적으로 어떤 css 선언을 적용시킬 것인가?를 결정
  - 가중치로 싸움 (class 선택자와 요소 선택자 - class가 이김)
  - 1. !importance (Cascade의 구조를 무시하고 강제로 스타일을 적용하므로... 사용 비권장)
  - 2. inline 스타일
  - 3. id 선택자 > class 선택자 > 요소 선택자
  - 4. 소스 코드 선언 순서
  - 가중치가 같다면? 코드 상 선언 순서가 나중인 것이 적용됨
  
### 선언 Declaration
"무엇을" 선택된 요소에 적용할 스타일을 구체적으로 명시하는 부분
- 속성과 값
  
### 속성 Property
스타일링하고 싶은 기능이나 특성을 의미
### 값 Value
- 단위
  - 웹 디자인에서는 반응형 웹과 접근성 때문에 상대 단위가 더 중요
  - 값이 0일 때는 단위 생략 권장
  - 절대 단위 : px, pt, cm
  - 상대 단위 : %, em, rem, vW, vh
    - em : 부모 요소의 크기에 따라 자식 요소 크기 결정
    - rem : 최상위 요소인 <html>의 font-size 기준으로 크기 결정

| 단위 | 기준 | 장점 | 단점/주의사항 | 추천 사용처 |
| :---: | :--- | :--- | :--- | :--- |
| **px** | 화면의 픽셀 | 직관적, 고정된 크기 | 접근성/반응형에 불리 | `border-width` 등 절대적 크기가 필요할 때 |
| **em** | 부모 요소의 `font-size` | 부모에 따라 유연하게 변경 | 중첩 시 계산 복잡 | 특정 컴포넌트 내부에서만 상대적 크기 조절이 필요할 때 |
| **rem** | `<html>`의 `font-size` | **일관성, 유지보수성, 접근성** | 루트 폰트 크기에 의존적 | 웹사이트 전반의 `font-size`, `margin`, `padding` 등 |
| **%** | 부모 요소의 크기 | 컨테이너에 맞춰 유동적으로 | `font-size`에 사용 시 `em`과 유사하게 동작 | `width`, `height` 등 레이아웃 구성 시 |
