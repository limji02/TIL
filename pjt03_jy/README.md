## 3. 핵심 학습 내용
* **Bootstrap Grid 시스템**: `row`, `col` 클래스를 활용하여 복잡한 레이아웃을 효율적으로 배치하는 법을 익힘.
* - portfolio.html에서 class 속성을 col-md-6으로 줘서 화면이 중간 크기(768px) 이상일 때 전체 12칸 중 6칸씩 차지하게 구현했다.
* - index.html에서는 bootstrap의 `row`, `col`를 쓰진 않았고, style.css에 CSS Grid로 활용했다. 'profile-grid (CSS Grid)'의 'display: grid; grid-template-columns: 1fr 1fr;' 속성을 통해 왼쪽(사진)과 오른쪽(투자 스타일)을 1:1로 나누었다. 이는 Bootstrap의 'row - col-6' 구조를 CSS로 직접 구현한 것과 같다.
* **반응형 웹 디자인**: Media Query를 통해 해상도(768px)에 따라 요소의 배치가 동적으로 변하는 원리를 이해했다.
* **Semantic Tag 및 Input 속성**: 데이터의 성격(이메일, 숫자, 읽기 전용)에 맞는 올바른 HTML 태그 사용의 중요성을 학습했다.
* **CDN** : 오늘 배운 CDN을 활용하여 구글 폰트에서 적절한 폰트를 가져와 썼다.

## 4. 어려웠던 점 및 해결 방법

* **문제점**: 
  1. 각자 파일을 하나씩 맡아 만들고 합치는 과정에서, 네비게이션 바의 위치가 상단 고정되지 않고, 중앙에 위치하는 문제가 있었다.
  2. 해당 페이지 링크가 연결된 네비게이션 바를 구현. 페이지 이동 이후, 어느 페이지로 이동된 것인지 헷갈려 이를 네비게이션 바에 더 명확히 표시해야 할 필요성을 느꼈다.
* **해결 방법, 새로 배운 것과 느낀 점**: 
  1. 협업 시 파일을 합치는 과정에서 다른 style코드 적용 등 방지하기 위한 초기 설정의 중요성을 느꼈다.
  2. 네비게이션 바에 기존 class 속성 중 'active'를 적절한 위치에 옮겨 해결했다.

## 5. 생성형 AI 활용 결과 (심화)

* **사용 AI**: Gemini 1.5 Pro
* **프롬프트 내용**: "금융 앱을 만드려고 하는데,  신뢰감을 줄 수 있는 프로필 페이지 컬러 차트와 폰트를 추천해줘."
* **반영 사항**: 
  1. 추천받은 컬러 (solid #0d6efd)를 CSS 변수에 적용하여 통일감 있는 UI 구현.
  2. 마우스를 올렸을 때 버튼 색깔이 살짝 더 진해지는 효과를 구현했다.
  3. 'transform: translateY(-1px);' 버튼의 살짝 떠오르는 느낌을 구현하여 사용자의 동적인 느낌을 추가했다.
